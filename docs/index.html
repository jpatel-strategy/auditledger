Why it's trustworthy

Deterministic math

A classic 3-way match (Invoice ↔ PO ↔ Goods Receipt) in pure Python catches every discrepancy. No LLM ever performs the reconciliation arithmetic.

The LLM only recommends

It proposes AUTO-APPROVE / FLAG / ESCALATE with a confidence score and reasoning — but a hard guardrail forbids auto-approving anything the matcher flagged, and a Critic agent checks its consistency.

Immutable audit log

Every decision is appended to a hash-chained, append-only SQLite log. Any tampering is detectable, and any invoice's full disposition is explainable from the log alone.

Honest limitations (v1)

  • Synthetic data — invoices, POs, and receipts are generated from a fixed seed; results demonstrate the controls, not real-world extraction accuracy.
  • Single currency / jurisdiction — one tax rate, USD only.
  • Offline by default — without an API key the LLM steps use deterministic fallbacks; live-model token cost is not yet metered.
  • Assumption-based ROI — "hours saved" and the case-study volume rest on stated, editable assumptions, not measured studies.
